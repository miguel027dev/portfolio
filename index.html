Gosto de entender
o projeto inteiro.

Começo pelo que a pessoa precisa fazer. Daí conecto interface, API, dados e infraestrutura para entregar uma experiência que funcione no uso diário.

Depois do primeiro lançamento, volto aos detalhes: um fluxo confuso, uma resposta lenta, uma tela que precisa ficar melhor no celular. É nesse uso que o produto evolui.
